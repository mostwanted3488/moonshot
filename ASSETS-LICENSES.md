# Assets : à vérifier avant de vendre le plugin

| Fichier | Origine | Statut |
|---|---|---|
| `Anton-Regular.ttf` | Google Fonts, licence SIL OFL 1.1 (`OFL-Anton.txt`) | Libre, vendable dans un plugin |
| `MoonGrunge.ttf` | Police créée pour MOONSHOT (script `tools/build_grunge_font.py`) | Originale |
| `player_*.png`, `ball.png` | Dessins originaux (joueur, ballon) générés depuis `tools/export_visual_assets.py` | Originaux |
| `earth.png` | Découpe d'une image de la Terre fournie par toi (type NASA Blue Marble) | Vérifie la source exacte de ton fichier |
| `saw.png` | Découpe d'une photo de lame de scie fournie par toi | Vérifie que tu as les droits |
| `bg.jpg` (sol lunaire) | Photo du sol lunaire fournie par toi | Vérifie que tu as les droits |

Les stickers HARD/SOFT, l'onde néon, le joueur, le ballon et l'explosion sont dessinés en code ou originaux.
